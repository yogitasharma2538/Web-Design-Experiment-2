
# Personal Portfolio Website

## Experiment 2 – Web Designing Lab

### Aim
To design and develop a personal portfolio webpage using HTML and CSS.

### Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- GitHub Pages

### Description
This project is a personal portfolio website created using HTML and CSS. It contains information about my introduction, education, skills, interests and contact details.

The website includes:
- Home section
- About Me section
- Skills section
- Projects and Exploration section
- Contact section

### Features
- Simple and attractive design
- Pink and white colour theme
- Responsive layout for different screen sizes
- Navigation menu
- Contact form

### Files
- `index.html` – Contains the structure and content of the webpage.
- `style.css` – Contains the styling and responsive design.

### Hosting
The website is hosted using GitHub Pages.
